## 발견 후 수정한 항목

1. 온라인 토큰 적립에도 기존 도감 적립 보너스를 적용하도록 Swift 규칙을 사용.
2. 보너스 팩 예산은 개인 할인 가격이 아닌 원래 팩 기준 가격으로 계산.
3. 오리파 미개봉 봉투/카드 대응은 API에서 숨기고 경품 목록만 노출.
4. 상태 변경 없는 응답에서 URLSession 자동 캐시가 오래된 본문을 재사용하지 않게
   직접 ETag를 관리하고 네트워크 요청의 자동 캐시 재사용을 끔.
5. 서버가 Mac 사용자의 개인 시세 파일을 읽지 않도록 온라인/서버는 번들 시세 사용.
   카드 시세뿐 아니라 팩 시세와 도감도 버전 해시에 포함.
6. 새 계정의 초기 보상 판정을 클라이언트 호출 순서가 아닌 서버 불변 조건으로 처리.

## 알려진 한계

- 로그인/토큰 수집 진위 검증 없음: 계정 UUID 소지자는 해당 계정 접근 가능.
- 같은 사용량 원천을 여러 기기에서 보고하는 중복은 구분하지 않음.
- 서버 규칙은 macOS 전용. Linux 포팅과 온라인 마켓/교환은 다음 단계.
- 1,000개 초과 작업은 청크별 확정. 전체 사용자 선택량을 한 번에 롤백하지 않음.
- 시세는 서버와 앱의 동일 번들 버전 사용. 온라인 임의 시세 가져오기는 비활성화.
- 오래된 이벤트를 삭제하면 중복 방지 기록도 사라지므로 보관 축소는 별도 설계 필요.
- 네이티브 통신/패키지 실행을 검증했으며 설정 화면의 수동 클릭 검사는 별도.
- FastAPI TestClient에서 httpx 관련 상위 라이브러리 deprecation 경고 1건 있음.
